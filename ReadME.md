# Competitive Coding Questions

This repo will be used to git track the competitve questions I have solved over time and the ones I'll solve from now onwards. This will be usefull for me to revise and keep track of whatever I have solved. Currently I am starting with Codeforces questions. Maybe even Leetcode questions but mostly Leetcode questions are solved directly on the platform so those will only be questions I want to remember and practice properly. I'll also collect any other resources or algorithms/concepts I find important here.

Note: To keep the competitive spirit alive and to avoid any unethical practices that diminish the prestige of the coding contests, this repo refrains from posting solutions to the contest questions before the contest is over, to not promote any solution sharing/malpractice/cheating. This repo is strictly for keeping track of my cp practice.
